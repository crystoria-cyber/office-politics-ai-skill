# Contributing to Office Politics AI Skill

Thank you for helping make workplace navigation more ethical and evidence-based.

## What We Accept

- **Regional context modules** — new geographic/cultural workplace modules following
  the structure of `INDIA_CONTEXT.md`
- **Worked examples** — new scenarios following the format in `EXAMPLES.md`
- **Case studies** — must follow `RESEARCH_PROTOCOL.md` with full source links
- **Bug fixes** — corrections to factual errors, broken links, or outdated law references
- **Translations** — translate the core `SKILL.md` and `MASTER_PROMPT.txt`

## Standards

1. **Evidence discipline:** All factual claims must cite a primary or high-quality source.
2. **Epistemic honesty:** Separate facts from inferences from hypotheses.
3. **Ethics first:** Contributions must not teach deception, manipulation, or illegal tactics.
4. **No identifying information:** Anonymize all personal workplace scenarios.
5. **Source quality:** Prefer academic journals, official government documents, court records,
   and reputable journalism. Do not cite social media or anonymous forums as facts.

## How to Submit

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-contribution`
3. Follow the existing file format and heading structure
4. Include sources inline (not in a separate references section)
5. Open a Pull Request with a clear description of what you added and why

## Code of Conduct

Contributions must respect the dignity of all people discussed in examples or cases.
No content that demeans, stereotypes, or makes accusations without evidence will be accepted.
